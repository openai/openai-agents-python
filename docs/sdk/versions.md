# Releases and documentation

These guides describe the SDK preview. See [installation](installation.md) for preview availability and wheel setup. Use documentation and examples from the same release as your installed wheel.

## Machine-readable topic index

[topics.json](topics.json) lists package metadata and task aliases for coding agents. Paths resolve relative to this SDK guide. `status` is `unreleased` and `release` is `null` until a matching preview is published. `published_release` and `published_guide` are also `null` until then.

`source_ref` identifies the development branch. When working with unreleased source, fetch the index and linked files from one pinned commit. Contributor build instructions are in [CONTRIBUTING.md](https://github.com/openai/openai-agents-python/blob/feat/codex-harness/CONTRIBUTING.md).
